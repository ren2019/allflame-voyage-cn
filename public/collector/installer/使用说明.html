国服海图采集器：安装与使用

正在读取候选版本…

候选尚未公开发布。 安装ZIP随本轮验收材料提供；当前没有公开Release或额外镜像。目标为Windows x64，真实新组件运行、授权、游戏和新手体验仍待玩家验收。

工具被动读取你主动复制的海图与边界截图，不自动移动鼠标、按键、点击或扫描仓库，不上传图片或剪贴板。首次安装/更新需取得固定组件，准备成功后可在本机离线使用。

下载参考：小启动包不到0.1 MiB，之后组件最多约120 MiB；完整离线包约119 MiB，已附组件归档，不重复计下载量。空间参考：程序与缓存的准备目录约374 MiB；若缓存微软安装包约392 MiB，共享微软系统组件、候选ZIP、暂存和旧版本另计。Windows实际占用以验收为准。

第一次安装

  1. 下载与你要验收的版本相符的安装包。右键压缩包，选择“全部解压”，打开解压后的文件夹；不要直接在压缩包内运行。
  2. 双击“安装或更新国服海图采集器.cmd”。不需要先安装 AutoHotkey 或 Python，也不用输入命令、编辑配置或更改文件关联。
  3. 核对窗口中的版本、安装目录和下载内容，依次等待环境检查、下载、文件校验、准备组件、模型自检和创建快捷方式。下载阶段会显示大小和进度。
  4. 如果缺少微软原生运行库，会打开 Microsoft Visual C++ 安装窗口及正常管理员授权。核对 Microsoft Corporation，阅读许可并选择安装。若取消或要求重启，按窗口说明处理后重试，不能以此时的窗口退出当作安装成功。
  5. 看到“安装完成”后，双击桌面的“国服海图采集器”开始使用。桌面的“国服海图采集器使用说明”可重新打开本文。

默认安装在当前用户的固定应用目录，日常启动不依赖下载目录或AHK文件关联。正常安装不要求先打开管理员终端。若系统或组织策略阻止运行，请保留错误并联系设备管理员；不要关闭防护、关闭UAC或永久放宽全局执行策略。

第一次启动与管理员授权

双击桌面的“国服海图采集器”。Windows如询问“是否允许此应用对你的设备进行更改”，核对你正在启动本候选后选择“是”。系统窗口里的 Windows PowerShell / Microsoft Windows 属于Windows启动程序；采集器来自本项目，项目脚本没有受信任发布者签名。

国服游戏以管理员权限运行时，采集器也需要同等权限，才能接收相关操作。使用桌面主入口会申请正常授权；工具不保存密码，不用隐藏服务或计划任务跳过授权。

选择“否”时会提示“未启动：管理员授权已取消”。这时还没有启动采集器，重新双击桌面入口即可重试。若用另一管理员账号确认，仍应使用原安装用户登记的目录；若提示目录无权限，请联系设备管理员，不要把密码交给工具。

先等待“正在检查本机组件与加载中文模型，尚未就绪”，再确认浮窗出现工具版本、权限模式和“采集器已就绪”。出现窗口或进程不代表模型已准备成功。缺组件或版本不一致时，先按提示修复再采集。

重复启动时先回到已有浮窗，完成并导出正在进行的批次。不要为了重新启动而关闭尚未导出的内容。

采集海图

  1. 确认采集器“已就绪”。
  2. 在游戏里按F7开始，确认浮窗显示“采集中：0张海图”。
  3. 鼠标逐张悬停在已测绘海图上，手动按Ctrl+Alt+C取得高级复制文字，确认浮窗计数增加。
  4. 按F7结束；看到“内容已输出到剪贴板”后回网页Ctrl+V导入。
  5. 核对网页的新增、重复或拒绝提示及海图数量。

F7只是开始和结束收集，不会自动遍历仓库。只开始再结束、没有手动复制，不会产生海图数据。连续复制相同原文沿用重复保护，不承诺每按一次都增加一张；网页也会按现有库存和原文处理重复。

只读取十二条边界

  1. 不用先按F7。打开游戏的航程规划界面。
  2. 手动按住Alt，让十二条边界提示都显示，再按一次F8；继续保持Alt。
  3. 看到采集器提示“截图已完成，可以松开 Alt”后再松Alt。游戏自己的“已保存截图”不代表采集器已取得所需图片。
  4. 等待本地识别完成。此时不要按F7结束。
  5. 看到“已读取X/12处边界文字”及“内容已输出到剪贴板”后，回网页Ctrl+V导入，核对每个位置和网页实际匹配结果。

提示音只是辅助；Shift+F7或托盘“切换提示音”可关闭/恢复。静音时按浮窗文字等待、松Alt和导入即可。F8只读边界，不采集仓库海图。

同一批次采集海图和边界

  1. 按F7开始，逐张手动Ctrl+Alt+C采集海图并核对计数。
  2. 打开航程规划，按住Alt显示十二条边界，按F8；看到“截图已完成，可以松开 Alt”后松开。
  3. 等到本地识别完成，看到“已加入当前批次，请再按F7统一输出海图和边界”。
  4. 再按F7结束，确认内容已输出，然后回网页粘贴并分别核对海图和边界。

如果在截图或读取期间提前按了F7，当前批次不会因此结束或清空。先按浮窗提示等待读取完成，再按F7统一输出；不要把暂时没有输出当作空批次。

查看诊断与反馈

采集阶段有问题时，从任务栏右下角找到采集器图标，右键选择“查看本地诊断”。它会打开本机的最近一份采集诊断，包含时间、工具/OCR/模型兼容版本、权限、失败阶段及最近一次边界文字。若新截图失败但诊断中仍有边界文字，请看原文取得时间；旧文字不代表本次截图成功。维护问题可从桌面“国服海图采集器维护”选择“查看版本与诊断”；安装失败窗口也会显示本地记录位置。

诊断保存在本机，不自动上传。采集诊断不保存一般剪贴板内容、海图原文或整张截图；需要反馈时先查看内容，由你自行选择提交。网页未匹配文字也可以逐槽查看。不要提供账号密码；截图只由你主动选取并提供。

更新、修复与卸载

入口：桌面“国服海图采集器维护”，或采集器托盘“更新、修复与卸载”；解压包内也有“维护国服海图采集器.cmd”。维护窗口按提示输入选项数字；确认更新或卸载时输入窗口要求的“更新”或“卸载”，直接回车可取消，无需输入系统命令。

从旧版升级：0.2.2或0.2.3没有安装维护入口时，请取得新的候选ZIP、全部解压，双击新包里的“安装或更新国服海图采集器.cmd”，核对当前版本、目标版本和变化说明后确认；取消保留旧版。无需寻找旧版不存在的维护菜单。

更新：先结束并导出批次，再从托盘“退出”。取得目标版本的候选ZIP，打开维护入口，选择“更新采集器”，选中已下载的包，核对当前版本、目标版本与变化说明后确认。取消不改旧版；新文件下载、校验或自检失败时保留旧可用版本，按具体失败阶段重试。旧版准备成功后可离线采集，联网更新失败不应使其失效。

修复：选择“修复安装”，沿登记的固定来源检查并补回缺失或损坏组件。若本机保留的源包也损坏，按窗口提示重新取得完整候选、全部解压，再双击“安装或更新国服海图采集器.cmd”。不要手动编辑版本清单。只有重新自检成功才算恢复可用。

卸载：先结束导出并退出采集器，再选择“卸载采集器”，阅读移除范围后确认。只移除登记属于本工具的组件和快捷方式；网页库存/规划、本地诊断、主动保存的截图和样本、共享微软组件保留。无需卸载浏览器或清空网页数据。仍在运行时会要求先退出，不会自动结束正在采集的实例。

日常退出

先按当前流程完成输出并导入，再到任务栏右下角找到采集器图标；图标可能在隐藏图标里。右键选择“退出”。维护窗口里的“退出维护”只退出维护流程。

高级手工入口

  1. 从AutoHotkey官网安装v2，同版本OCR运行组件和模型需完整保留在脚本旁；不要用v1运行本脚本。
  2. 需与管理员游戏同等权限时，右键本脚本，必要时先点“显示更多选项”，选择“以管理员身份运行”；正常UAC由你确认。若没有该选项，请使用候选安装包的桌面主入口，不修改文件关联。不要禁用UAC或依赖隐藏提权。
  3. 先核对浮窗版本、权限和“采集器已就绪”，再按本文采集。普通玩家使用安装/修复入口；单独双击裸脚本不能替代完整组件准备。
