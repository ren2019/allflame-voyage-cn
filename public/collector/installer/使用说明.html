国服海图采集器：候选安装与启动

这是可审查的 Windows x64 候选，尚未公开发布；真实 Windows 授权、游戏操作与新手体验等待玩家验收。版本及摘要在随包 collector-package.json 与外部摘要文件中。工具只被动读取你主动复制的海图与边界截图，不自动操作游戏，不上传截图或剪贴板。

  1. 右键安装压缩包，选择“全部解压”；不要在压缩包内直接运行。
  2. 双击“安装或更新国服海图采集器.cmd”。安装窗口会显示版本、目录、下载量、校验与自检；普通路径不需要自己安装 AHK、Python 或输入命令。
  3. 如本机缺微软原生运行库，会打开 Microsoft Visual C++ 安装窗口及正常管理员授权。核对 Microsoft Corporation，阅读许可并选择安装；取消或要求重启时不会假报成功。已有兼容组件且实际模型能加载时跳过此步骤。
  4. 完成后使用桌面的“国服海图采集器”。正常管理员授权显示的是 Windows PowerShell（Microsoft Windows），本项目脚本没有受信任发布者签名。确认路径来自你认可的候选后选择是；取消则未启动，可重新双击。

管理员授权与游戏同权限是为了接收 F7/F8。使用其他管理员账号时，启动入口仍使用原安装用户登记的绝对路径；权限不足请联系设备管理员，不向工具提供密码。不要关闭 UAC、防护或永久放宽全局执行策略。

看到已就绪后再采集

准备与模型加载中不等于已就绪。浮窗显示版本及权限后：F7 开始海图采集，逐张悬停并手动 Ctrl+Alt+C，计数增加后 F7 结束，回网页粘贴。F7 不自动扫描仓库。

只读边界无需先 F7。打开航程规划，手动按住 Alt 显示十二条提示，再按 F8；看到本工具“截图已完成，可以松开 Alt”后松开。等待读取完成，依浮窗输出并在网页导入；F7 批次中的 F8 必须等待完成再 F7 结束。读到十二处文字不等于网页匹配十二条，未匹配可重试或手动补选。

读取与输出失败时

“截图中”继续保持 Alt；看到“截图已完成，可以松开 Alt”后可松开，等待“已读取 X/12 处边界文字”。混合批次会提示“已加入当前批次，请再按 F7 统一输出海图和边界”；识别中提前 F7 会提示等待，保留批次。独立 F8 会直接输出，不需要 F7。

只有“内容已输出到剪贴板”后才回网页粘贴。写入剪贴板失败时内容仍保留，可从托盘选择“重试输出内容”；活动批次会统一输出，不会只输出边界而漏海图。具体截图、识别或输出错误不会被空批次消息覆盖。游戏自身“已保存截图”不等于本工具截图成功。

读取数量不等于网页匹配数量。网页展开“查看未匹配边界文字”逐槽核对，可重试 F8 或手动补选。完整十二槽至少匹配一条时本次结果替换全套、未匹配槽留空；全失败保留原边界；部分输入只更新成功槽位。

托盘“查看本地诊断”用记事本打开原安装目录 diagnostics/collector-last.txt，包含版本、权限、失败阶段和最近边界原文及其取得时间；新截图失败时旧原文仍有原时间标记。仅保存在本机，不记录一般剪贴板、海图原文或整图，不自动上传；裸脚本只使用自己的临时目录。主动另存的资料请自行保留。

重复启动、退出与失败

重复启动保留正在运行的实例与未导出批次。退出：任务栏右下角找到采集器图标（可能在隐藏图标中），右键选择“退出”。安装前先结束导出再退出。

下载、摘要或缺组件错误：保留窗口原文与本地诊断，重新双击同一安装入口重试。网络不可达可使用完整离线候选包，不存在的镜像或公开 Release 不作承诺。安全或组织策略拦截时联系设备管理员，不关闭防护。OCR 错字或网页不匹配需核对文字及位置，不能反复提权冒充解决。

本候选安装与脚本支持范围尚待真实 Windows 验收；跨平台归档检查不代表 Windows、UAC 或游戏通过。安装使用当前用户的固定目录，不改网页库存与规划。来源：集成 PR #78。
