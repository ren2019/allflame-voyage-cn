# 国服采集器覆盖海图与边界，并保持游戏操作由玩家执行

2026-10-28，用户确认国服采集器的目标同时覆盖海图高级复制文本的批量汇总，以及十二条边界的截图识别与按位置导入，可分阶段实现和验收。两部分全部完成并由用户手动验收后，一次性发布；不单独发布只有海图采集的阶段版本。

游戏内悬停、复制和按住 Alt 等操作全部由玩家执行；采集器负责监听剪贴板、截图识别与汇总输出，不自动遍历仓库、移动鼠标、点击或代按游戏按键。即使库存有一百张海图，也仍需玩家逐张复制；这一边界延续现存被动采集器的设计，将适配集中在采集与识别，排除自动操作游戏的另一种产品方向。

国服客户端现场效果由用户手动验收，覆盖海图批量采集与十二条边界的识别和位置导入；不将额外建设截图样本集或自动化 Windows OCR 验证作为前置要求。

用户确认以最小适配为原则，沿用原版重复处理：采集器忽略连续相同的海图文本，网页按原文与库存数量去重，不新增数量确认入口。边界沿用粘贴后直接更新的流程，不新增导入预览；完整十二槽扫描至少匹配一条时以本次结果替换，未匹配槽位留空；全失败保留原边界；部分扫描仅更新匹配成功的槽位。

保留原版按 F7 后显示的计数浮窗，并在该浮窗提示采集器能够检测到的错误。浮窗继续承担采集状态、海图数量、边界读取进度与操作提示，避免新增弹窗或配置界面。网页完成词缀匹配后才能判定的错误仍属于网页导入反馈，采集器不能将读取到文字的数量称为网页匹配成功数量。

沿用 Windows 与 AutoHotkey v2，以及原版按窗口尺寸缩放的定位方式，不额外设置首版分辨率或显示模式白名单；实际国服显示问题在验收中校准。OCR 沿用 Windows 本地识别，仅补充简体中文支持，不接入云端服务；缺少中文 OCR 组件时在浮窗提示，边界仍可手动选择。

上述方案已经用户确认。本记录记载设计决策，不表示功能已经实现、通过验收或发布。

2026-10-28 发布安排更新：用户在 Windows 使用 Ctrl+C 完成海图采集并在原生产网页导入通过，随后明确要求将本波全部更新发布到生产，并保留其他会话已发布的功能。因此不再以全部边界现场验收作为发布前置条件，改为从包含最新主分支功能的完整版本统一发布，边界 OCR 和十二槽位置在生产继续现场核对。该发布授权不等于边界现场验收通过；被动操作边界和其他实现决策保持不变。
