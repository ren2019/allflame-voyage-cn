诊断路径：安装入口显式登记的原 InstallRoot 下 `diagnostics/collector-last.txt`；换管理员账号不改用另一人的 LocalAppData。裸脚本无登记路径时使用本工具自己的 Temp 子目录。诊断不保存一般剪贴板、海图原文或整图；最近边界原文可能来自先前读取，必须看取得时间，不能因其存在推断本次截图成功。AHK无法知道网页词缀匹配结果；网页详情才是未匹配原文。

实施验证使用现有 `npm test`、`tests/browser/import.spec.ts`、`tests/collector/test_border_ocr.py` 和公共候选包CLI。Windows允许项仅为既有AHK `/Validate /ErrorStdOut=UTF-8` 与原PowerShell5.1 Parser AST；没有启动新采集器、安装运行时、授权或游戏操作。最终候选不得将这些自动通过写成整套现场已验收。
