# #75 维护候选与证据边界

维护候选版本 0.2.4，沿用 #73 的固定组件、当前用户安装登记与中文安装路径。#74 的被动采集、诊断与错误反馈保持独立；真实 Windows 激活、UAC、运行中批次、游戏与新手结果仍交 #77，不能以跨平台文件检查代盖通过。

## 玩家入口

- 旧 0.2.2／0.2.3 没有已安装的维护菜单。升级使用新包内的“安装或更新国服海图采集器.cmd”，显示当前／目标版本和变化说明后可确认或取消，不让玩家寻找不存在的旧菜单。
- 安装维护版后：桌面“国服海图采集器维护”、安装目录“维护国服海图采集器.cmd”、托盘“更新、修复与卸载”。菜单为“查看版本与诊断／更新采集器／修复安装／卸载采集器／退出维护”。
- 更新选择已取得的固定版本 ZIP；相同版本进入检查／修复。缺模型仍可读取最小登记并进入修复，固定安装源也损坏时不执行它，改用重新解压的完整候选中文安装入口。
- 操作前结束、导出并退出采集器。维护不杀进程，低权限读不到其他 AHK 命令行时如实说明未知，不能将其当作没有活动实例。

## 文件事务与资料保护

目标归档逐项摘要、完整本机模型自检通过后才激活。精确 SHA 缓存复用未变化组件；离线日常启动仅使用已经准备的本机组件，不依赖更新网络。没有 `SkipSelfTest`、模拟 `ready:true` 或模型绕过入口。

切换持有与 AHK 相同的操作系统运行锁；稳定 PowerShell／CMD／说明、原用户桌面快捷方式、文件归属清单和当前／前次登记共同备份。当前绑定最后写，提交前失败或未提交中断按同一事务记录恢复全部入口。已经等于原字节的只读目标不重复写入；用户在事务后另作修改的内容不强行覆盖。提交后的清理失败与激活失败分开提示。

新版本保留完整按文件归属的清单。卸载只移除登记且摘要相符的内容；安装根或版本目录中新保存的截图、诊断、样本及其他未登记／已修改文件保留，目录非空也不强删。不跟随被替换为外部链接的登记路径。网页存储、用户浏览器目录和共享微软运行库没有清理入口。缓存中的微软原始安装包与系统共享运行库是不同范围。

## 可自主验证

既有公开 CLI、真实归档及文件系统边界：

```sh
VOYAGE_PWSH=/absolute/isolated/pwsh VOYAGE_COLLECTOR_COMPONENTS=/absolute/fixed-archives VOYAGE_OLD_COLLECTOR_PACKAGE=/absolute/0.2.2-starter.zip python3 -m unittest discover -s tests/collector -v
```

其中图像 OCR 的真实再次回放还需使用固定隔离 Python 环境并显式传 `VOYAGE_OCR_IMAGE`；未提供时明确跳过，不能称本轮再识别通过。

维护回归使用真实旧候选和新候选的公开准备入口，核对版本对、缓存时间不变、不联网、坏摘要不改原绑定、可取消、缺模型的独立修复准备及固定源坏时拒执。中断恢复测试是明确的文件系统 fixture，真实写入并恢复稳定入口／快捷方式字节与当前／前次登记；它没有伪造 OCR 就绪，也没有声称已经在 Windows 创建或运行快捷方式。卸载 fixture 实际删除登记文件，验证版本目录中的玩家截图、诊断、根外库存和已改快捷方式仍保留，外部链接拒绝清理。

上述检查不能证明 Windows 原生激活或授权已通过。#77 仍需在玩家认可的测试环境核对旧版→目标实际切换、缺组件修复、失败后的旧版可用、离线使用及卸载。只读 launcher 能否在目标 Windows 稳定触发切换失败也按实际记录；没有失败样本就保留“缺证据”，不勾选通过。
