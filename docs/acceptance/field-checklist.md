## 国服采集器（#54）

2026-10-28 用户确认已在 Windows 使用 Ctrl+C 完成海图采集，并在原生产网页导入通过；该反馈未覆盖边界 OCR。用户随后明确要求将本波全部更新统一发布，放大后的浮窗和以下边界项目在生产继续核对，不预填为通过；不另要求建设截图样本集或自动化 Windows OCR 平台。

1. 安装 AutoHotkey v2 并运行本次候选脚本，游戏与采集器权限一致。记录 Windows、游戏版本、窗口尺寸及显示缩放，确认找到实际游戏窗口。
2. F7 开启后核对放大的中文计数浮窗；逐张手动 Ctrl+C（需要完整高级属性时 Ctrl+Alt+C），计数增加。连续复制同文只记一次；再次 F7 后到网页 Ctrl+V，核对海图字段与数量，重复导入不无故增加库存。
3. 在 F7 采集期间，自己按住 Alt 显示十二条边界，再按 F8。截图完成提示后松开，确认本机识别完成，F7 结束后一次粘贴海图与边界。
4. 对照游戏核对十二个边界位置和具体词缀，特别是数字档位、提高／降低及每连接效果。浮窗的文字读取数量不等于网页匹配成功数量；未匹配的位置手动选择。
5. 不启用 F7，单独按住 Alt 后按 F8，完成后直接粘贴，只更新边界；确认既有海图库存保留。全部未匹配时原边界保留；部分扫描只覆盖匹配位置；完整扫描有匹配时未匹配槽留空。
6. Shift+F7 静音后确认计数和浮窗仍显示；若遇未找到窗口、缺少中文 OCR 组件、截图或识别失败，确认错误在浮窗提示，海图仍可手动复制、边界仍可手动选择。缺组件时按浮窗安装指引处理，不要求卸载现有组件来制造错误。

将海图采集、浮窗与热键、边界文字和十二槽位置分别写为“通过”“失败”或“未测”，失败附最小复现。未获得实际结果前，不把自动化检查描述为国服现场验收通过。
